# Programa-git

Repositorio de práctica de Git y GitHub Desktop - SENA ADSO



\## Objetivo del repositorio



Este repositorio se utiliza para desarrollar los ejercicios prácticos de control de versiones de la formación en Análisis y Desarrollo de Software (ADSO) del SENA.



Los cambios se gestionan mediante GitHub Desktop, permitiendo registrar versiones y sincronizar el repositorio local con GitHub.
